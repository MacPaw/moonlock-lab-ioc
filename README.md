# moonlock-lab-ioc

## Disclaimer

This repository contains indicators of compromise (IOCs) — domain names, URLs and SHA-256 file hashes — observed by MacPaw’s Moonlock team in connection with malicious activity. They are published for defensive, research and educational purposes only, to help security teams detect and block threats.


Do not visit the listed domains or URLs or download files matching these hashes. Some may still host live malicious content.


Indicators reflect our analysis at the time of observation. Infrastructure changes hands: a domain may have been compromised, cleaned up, or re-registered by an unrelated party since. Inclusion of an indicator does not mean that its current owner is responsible for malicious activity. The data may contain errors or false positives; validate it before using it for blocking decisions.
